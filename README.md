# 🏢 SME Management System - Frontend 

## 📝 Overview
The Frontend for the **SME Management System**, developed to provide a modern, high-performance interface for Small and Medium Enterprises. This module focuses on digitizing complex manufacturing workflows and production order tracking with a focus on user experience and rapid development.

## 🚀 Key Features
* **Production Order Tracking**: Real-time status monitoring of manufacturing requests.
* **Product Management Dashboard**: Interactive interface for managing product catalogs and specifications.

## ⚡ Development Strategy: Vibe Coding
This frontend was developed using **AI-assisted coding (Vibe Coding)** techniques. 
* **Rapid Prototyping**: Leveraged AI tools to quickly transform business requirements into functional UI components.
* **Efficiency**: Significant reduction in development time for complex forms and data-heavy tables.
* **Consistency**: Ensured a uniform design language and high-quality code through AI-driven refactoring.

## 🛠 Tech Stack
* **Framework**: NextJs
* **UI Components**: Shadcn
* **API Consumption**: Fetch for RESTful API integration 
* **State Management**: React Hooks


## 🔧 Installation & Setup

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/VuBinhVL/FE-SMEManagementSystem.git
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Run Application**:
    ```bash
    npm start
    ```
